# L6_L7_17_electricity_bill — Electricity Bill

Lab 7: Fuzz Testing for Input Validation Bugs

## About

Exploration of fuzz testing as an automated security and quality assurance technique using the **Hypothesis** property-based testing framework. Edge-case inputs (malformed strings, empty values, None, delimiter bugs) were automatically uncovered and fixed by defensively hardening `electricity_bill.py`.

## Files

| File | Description |
|------|-------------|
| `electricity_bill.py` | Defensively hardened module resilient to fuzzing |
| `test_electricity_bill.py` | Hypothesis property-based fuzz test suite |
| `Lab_7_FuzzTesting_Report.docx` | Editable Word document of the lab report |
| `Lab_7_FuzzTesting_Report.pdf` | Final lab report document with terminal screenshots |
| `Lab_7_FuzzTesting_Student_Handout.pdf` | Lab assignment instructions and handout |
| `screenshots/` | High-resolution terminal output screenshots for all steps |

## Running Tests

### 1. Run the Application
```bash
python electricity_bill.py
```

### 2. Run Hypothesis Fuzz Tests
```bash
pytest test_electricity_bill.py -v
```
Result: **3 passed** across hundreds of pseudo-random edge-case inputs generated by Hypothesis.
